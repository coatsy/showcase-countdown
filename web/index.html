showcase-countdown

An NTP-synchronised event countdown for the M5StickC PLUS SE and M5StickS3. Match your device below, plug it in over USB, and install directly from this page.

M5StickC PLUS SE

Translucent orange case with an 8-pin Hat-Bus. Windows requires the FTDI VCP driver.

M5StickS3

Black case with a blue front button and 16-pin Hat2-Bus. Uses native USB.

One installer supports both models. It detects the connected chip and selects the correct firmware.

This browser cannot talk to serial devices. Open this page in Chrome, Edge, or Opera on a desktop computer. Installing requires a secure (https) connection.

Before you start

  • Use Chrome, Edge, or Opera on a desktop. Safari and mobile browsers cannot access serial ports.
  • PLUS SE on Windows: install the FTDI VCP driver. The device will not appear as a COM port without it, and some machines need it installed twice.
  • StickS3 download mode: hold the side button until the internal green LED flashes, then release it. After installation, short-press the side button to start the firmware.
  • Close any other program using the port, including the Arduino IDE or a PlatformIO serial monitor.

What happens

  1. Pick your Stick's serial port when the browser asks.
  2. The firmware is written, which takes about a minute.
  3. You are prompted for your Wi-Fi network. Credentials are sent over the USB cable and saved on the device.
  4. The Stick syncs its clock from NTP and starts counting down.
Your Wi-Fi credentials are never part of the download. The published firmware contains no network details at all: it asks for them after installing and stores them on the device, so this page cannot see them and neither can anyone else who downloads the image.

Configure your device

Change the title and time zone on a Stick that is already running. This talks to the device over the same USB cable, so nothing is sent anywhere else.

Formatting help

Separate several titles with | and the device cycles through them. A title too wide for the screen scrolls instead of being cut off.

Open a colour with a tag and return to white with [/], for example [red]Launch[/] Day. The named colours are:

  • [red]
  • [green]
  • [blue]
  • [yellow]
  • [cyan]
  • [magenta]
  • [white]
  • [orange]
  • [grey]
  • [skyblue]
  • [pink]

Any other colour uses [#RRGGBB], such as [#00A4EF]. The panel is RGB565, so shades are approximate and brand colours often read duller than the named equivalents. Plain [blue] is very dark on this screen; [skyblue] shows up far better.

A tag that is not recognised is drawn as literal text rather than silently dropped, so a typo is visible instead of swallowing the words after it.

The device stores a fixed offset from UTC and does no daylight-saving calculation of its own. This page reads the offset your chosen zone is on right now and sends that, so re-apply it after a daylight-saving change.

Connect your coding agent

Your device's four-digit claim code identifies it on the event MCP server. Your coding agent can use that connection to send messages, play sounds and control the lights. Read the MCP connection guide for GitHub Copilot, Claude Code and Cursor setup, example commands and troubleshooting.

Afterwards

The Stick has a few controls once it is running:

  • Single-click button A to force a clock re-sync, double-click to toggle the Grove lights.
  • Button B shows the diagnostics screen.
  • Over serial at 115200 baud, send ? for the full command list.

To move the device to a different network, run the installer again and choose the Wi-Fi option, or send w over serial to forget the stored credentials.
